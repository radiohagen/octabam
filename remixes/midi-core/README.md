# MIDI Core

The complete [upstream Core](../octabam-core/README.md) selection,
including RLEN PLEN, plus MIDI Scales, Follow, HARM, Loopback, Part State
and SRAM. SEQUENCER EVENTS and EDIT EVENTS coordinate transport, accepted
MIDI output, held-trig editing and native clipboard copies. The separate
Loopback/Scenes routing adapter preserves each source track's destination.

All upstream effects, settings and slot assignments are retained. No extra
synth machines or POST FADER variant is selected. Software verification of
the composed image is recorded with the private package; hardware acceptance
is pending. Use a new project and keep backups when changing effect layouts.

See [the MIDI family guide](../../docs/site/guide/midi-family.md) for packaging.
