# Harmony MIDI

MIDI Harmony with MIDI Scales, Loopback and KITS, plus its required
STORE, MIDI Part State and MIDI SRAM support. Stock effects remain available.
This test selection exercises shared Part, project, routing and scale behavior.
MIDI Scenes cannot share this Loopback selection without a separate bridge.
PLOCKS P2 and MIDI Follow require additional composition bridges; EUCLID uses
conflicting transport hooks. They are not selected here.

Hardware testing is outstanding. See [Harmony](../../../modules/midi-harmony/README.md).
