# Harmony Scenes

MIDI Harmony with MIDI Scales, MIDI Scenes and KITS, plus the required STORE,
MIDI Part State and MIDI SRAM support and stock effects. This test selection
exercises degree and chord state during scene changes and kit recall.
Loopback and PLOCKS P2 need separate bridges when combined with these modules.

Hardware testing is outstanding. See [Harmony](../../../modules/midi-harmony/README.md).
